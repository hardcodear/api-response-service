# Seguridad

## Versiones mantenidas

Se reciben correcciones de seguridad para la última versión estable de la serie `2.x`. La serie `1.x` no recibe nuevas correcciones; migrá a `2.x` y revisá las notas de migración del README.

## Reportar una vulnerabilidad

No abras un issue público con detalles de una vulnerabilidad. Enviá un reporte privado a [ricardobazan@hardcode.ar](mailto:ricardobazan@hardcode.ar), indicando la versión afectada, pasos de reproducción y posible impacto. No incluyas credenciales ni información personal real.

El mantenedor evaluará el reporte y coordinará una corrección antes de divulgar los detalles. No se garantiza un plazo fijo de respuesta.
